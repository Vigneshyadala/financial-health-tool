## ============================================================
## TROUBLESHOOTING
## ============================================================

Problem: pip command not found
Solution: Install Python from python.org (3.8+)
          Add to PATH during installation

Problem: npm command not found
Solution: Install Node.js from nodejs.org (14+)

Problem: Port 8000 already in use
Solution: Change port in backend/main.py:
          uvicorn.run(app, host="0.0.0.0", port=8001)

Problem: Port 3000 already in use
Solution: When npm asks, press 'y' to use different port

Problem: Module not found
Solution: Reinstall dependencies:
          Backend: pip install -r requirements.txt
          Frontend: npm install

Problem: CORS errors
Solution: Backend main.py already has CORS configured
          Check that VITE_API_URL is correct in Vercel

Problem: File upload fails
Solution: Use sample_data.csv (known to work)
          Check file size (under 10MB)
          Verify file format (CSV, XLSX, or PDF)
